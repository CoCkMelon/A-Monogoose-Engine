PITFALLS HIT THIS SESSION (do not rediscover)
- SDL_main.h: Debian SDL3's SDL.h does NOT pull SDL_main.h; the bootstrap
  defines SDL_MAIN_USE_CALLBACKS + includes <SDL3/SDL_main.h> explicitly in
  ONE TU. Tests define SDL_MAIN_HANDLED (they own main()).
- GL function typedefs: use <GL/glcorearb.h>; Khronos PFN names are ALL
  CAPS: PFNGLCREATESHADERPROC (not PfnglCreateShaderProc).
- EGL surfaceless has NO default framebuffer: tests must create an FBO and
  bind it before rp_begin_frame; read pixels from the FBO.
- Baked-atlas header: never name a size macro like the include guard
  (AME_FONT_ATLAS_H height collided with the guard -> now ..._WIDTH/_HEIGHT).
- text_draw_world maps glyph PIXELS to world units directly: scale the pose
  (see card_label_pose gs / billboard_pose scale in mem_app.c).
- Generated font_atlas.c: glyph table must be emitted closed BEFORE the
  atlas byte array opens (array nesting).
- CMake: tools/ (bake_font) must come BEFORE the engine libs (they link
  ame_font). asyncinput's own "smoke" ctest leaks: BUILD_TESTING is toggled
  OFF around its add_subdirectory.
- pass camera CENTER in 2D: world origin = screen center with pos(0,0).
