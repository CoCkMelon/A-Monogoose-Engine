  (rayRaw = raw camera_screen_ray dir; ray_hits: pos + D*ray = P),
  Ame/Shader (vertShader = gl_Position line, gpuViewport = divide +
  viewport; shader_pixel_x/y == analytic pixel; picking_from_shader =
  end-to-end GPU-pixel -> analytic-ray -> exact hit). 27 kernel-checked
  theorems + 4 quarantined native_decide checks.
- LEAN-RAT PITFALLS (cost the most time):
  * Kernel CANNOT reduce Rat ops (extern): `decide` is DEAD for all Rat
    facts, even 1+1=2. Workarounds: numeral adds/muls via
    `simp [Rat.add_def, Rat.normalize_eq]`; DIVISION is not
    simp-evaluable at all (divInt blocks) -> concrete division checks
    must use native_decide (disclosed) or be avoided.
  * Structure fields cannot share binders (refA refB : Nat -> error).
  * `+`/`*` on own structures go through instances that simp CANNOT
    unfold: write defs used by proofs with explicit V3.add/V4.add
    nesting, and state hypotheses with explicit V3.add.
  * `show` requires DEFEQ, and Rat add is NOT assoc-defeq (extern):
    parenthesization of sums in `show` patterns must match exactly.
  * rw direction discipline: rw [h] replaces h's LHS; rw [<- h] its
    RHS; `rw ... at h'` fails hard if the pattern is absent (no
    partial application) - rw the goal, carry hypotheses manually.
  * Full-AC simp (mul_comm+assoc+left_comm+add_*) can TIMEOUT on 4x4
    matrix products: `set_option maxHeartbeats 4000000 in` fixed
    mulv_mul (60s build). Keep simp sets minimal per goal.
  * Long chained projections collect paren bugs; use local defs
    (vp3) + `simp only [vp3]` to unfold.
